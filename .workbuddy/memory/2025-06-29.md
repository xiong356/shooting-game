## Valorant 训练靶场 - 前端游戏开发

创建了完整的 Web-based 3D 第三人称射击训练游戏：

**完成事项：**
- 搭建 Three.js 3D 场景：训练场环境（地面、墙壁、射击道分隔、距离标记、掩体柱）
- 实现第三人称相机系统：鼠标控制视角旋转，WASD 移动 + 空格跳跃
- 创建几何体角色模型：躯干/四肢/头部/武器，Valorant 风格配色
- 实现射击系统：射线检测、身体/爆头双区判定、枪口闪光、弹道轨迹
- 9 个目标靶：7 静态 + 2 移动靶，击中后物理倒下动画 + 自动重生
- 分数系统：身体100分/爆头300分，连击显示，命中率统计
- 60秒计时回合 + 结束评分 (S/A/B/C)
- Valorant 风格 HUD：斜角切割面板、准星、弹药、击杀信息流
- Web Audio API 合成音效：枪声/命中/爆头/换弹/结束
- 粒子特效系统 + 枪口闪光 + 弹道拖尾
- 移动端适配：虚拟摇杆 + 射击按钮 + 滑动视角 + 响应式布局
- 指针锁定 + 暂停/续玩机制 + 标签页隐藏暂停

**文件：**
- `index.html` - 主入口 + UI overlay
- `css/styles.css` - Valorant 风格样式 (~500行)
- `js/game.js` - 完整游戏逻辑 (~1400行)

**技术：** Three.js 0.160 CDN, ES Module, Web Audio API, Pointer Lock API

**15:05 - 武器不可见彻底修复（第3次迭代）：**
- **真实根因**：加载阶段对 `ak47Model.position` 做了居中偏移，但 `init()` 中 `clone()` 后用 `position.set()` 覆盖了这个偏移。几何体中心偏离相机空间原点 → 武器渲染在视野之外
- **重构**：
  - 加载阶段：只 `setScalar(autoScale)` + 材质配置，**不再动 position**
  - `init()` 阶段：`clone(true)` → `Box3` 算包围盒 → `position.set(-center)` 居中 → `position.add(0.22,-0.2,-0.5)` 定位
  - 新增 **调试红方块**（0.08³, MeshBasicMaterial #ff0000, z=-0.4）挂在 fpsWeapon 下，一眼判断渲染管线是否正常
- `camera.near`: 0.5 → 0.05（彻底排除近裁剪面嫌疑）
