## 任务：排查「点击 index.html 无法进入游戏」

### 根因（已实测确认，非推测）
用 CDP 探针在真实 Chrome 里分别加载 `file://` 与 `http://` 两种协议，对比点击前后 DOM 状态：

| 场景 | 点击后 startScreen | hudHidden | bootGuard | 结论 |
|---|---|---|---|---|
| `http://127.0.0.1:3000` | hidden ✅ | false ✅ | false | 正常进入 |
| `file:///D:/.../index.html` | **不隐藏 ❌** | **true ❌** | — | **点击完全无反应** |

控制台错误（file:// 场景）：
```
Access to script at 'file:///.../js/game.js' from origin 'null'
has been blocked by CORS policy: Cross origin requests are only supported for
protocol schemes: chrome, chrome-extension, ... data, http, https, isolated-app.
Failed to load resource: net::ERR_FAILED
```

**即：直接双击 index.html 时，浏览器按 CORS 策略拒绝加载 `type="module"` 脚本，
game.js 一行都没执行 → 事件监听没挂上 → 按钮点了没反应，且页面无任何提示。**

### 附带的第二个真实缺陷：ak47_2.glb 文件损坏
```
实际大小 = 2056192 bytes
GLB 头声明 = 5068520 bytes   →  缺 3012328 bytes（约 2.9MB）
```
GLTFLoader 抛 `Invalid typed array length: 187926`，枪模加载失败退回几何体。
（`ak47.glb` 47684 bytes **完整**，29 meshes 可用）

### 关键决策
1. **触发条件三层**：手动 R（提前换弹）/ 空弹自动换弹（新增，原来是只显示提示不换弹）/ 拒绝条件（满弹、换弹中、非 playing）
2. **动画**：6 个关键帧 × 6 通道（位移 xyz + 旋转 rx/ry/rz），三段语义
   - 0~0.22 收枪放下 → 0.22~0.55 拔插弹匣 → 0.55~1.0 上膛复位
3. **弹药时序**：`RELOAD_MAG_IN_AT = 0.55`，弹药在**插弹匣那一帧**补满，不是换弹结束才补满
4. **音频对齐**：`playReloadSound()` 拆成 `playMagOutSound` / `playMagInSound` / `playBoltSound`，
   由状态机在对应进度触发，替掉原来的 `setTimeout(400)` 硬编码（暂停时会声画错位）

### 数值验证抓到的真实缺陷（重要）
初版 `getReloadPose` 用**逐段独立 easeOutCubic**，测试发现关键帧边界存在速度突变：
- 单帧姿态跳变 0.0147 → 折算 60fps 单帧约 **9.4°**，肉眼是明显抽动
- 根因：逐段缓动使每段两端斜率都归零，跨边界时速度从 0 突跳到大值
- 修复：改用 **Catmull-Rom 样条**（一阶连续，端点复制自身保证首尾严格归零）
- 同时收敛了关键帧摆幅（rz 原设计在 0.22s 内摆动 42°，过于剧烈）
- 结果：边界速度突变 **9.4°/帧 → 0.22°/帧**

### ⚠️ 验证方法论修正（最重要的一条）
**`node --check` 对 `.js` 文件不可靠**：实测同一份含多余右括号的文件，
`node --check x.mjs` 退出码 **1**（能抓到），`node --check x.js` 退出码 **0**（漏检）。
原因：`.js` 走 CommonJS 解析路径。
→ 本项目所有 JS 静态检查必须用 **`.mjs` 副本**，脚本 `esm-lint.js`（同时做 HTML/JS id 交叉校验）。

### 新踩的坑（CDP 测试相关）
- 触摸横向拖拽会被 Chrome 识别为 **overscroll 返回手势**，把页面导航回上一页（表现为白屏）。
  必须加 `--disable-features=OverscrollHistoryNavigation`
