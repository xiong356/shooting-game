## start.bat 双击自动启动游戏

**需求**: 双击 start.bat 后自动启动游戏（服务器 + 浏览器）。

**改动**:
1. `server.js`：
   - 服务器监听成功后延迟 800ms 自动调用 `openBrowser()` 打开默认浏览器（兼容 Win/macOS/Linux）
   - 添加 `server.on('error')` 处理 EADDRINUSE：端口被占用（上次服务器还在运行）时，直接打开已有服务器并 `process.exit(0)`，避免重复启动多个实例
   - 注意：EADDRINUSE 是 EventEmitter 的 error 事件，不能用 `process.on('uncaughtException')` 捕获，必须用 `server.on('error')`
2. `start.bat`：
   - 开头加 `chcp 65001 >nul` 避免 UTF-8 中文乱码
   - 优先 node 启动（server.js 支持 .glb MIME），python 作兜底

**测试**: server.js 语法 OK；index/glb HTTP 200；EADDRINUSE 分支测试通过（检测占用→打开→exit 0）。

**坑**: 沙箱测试时后台 node 进程占用 3000 端口导致误报，需先 taskkill 清理（Git Bash 用 taskkill //F //PID，单斜杠会报无效参数）。

## 枪械后坐力系统

**需求**: 为枪械增加后坐力。

**实现**（js/game.js）:
- 新增状态：`recoilPitch`（垂直后坐）、`recoilYaw`（水平随机偏移）、`weaponKick`（武器视觉脉冲）
- `shoot()` 射击时施加：`recoilPitch += 0.012`（上限 0.30）、随机水平偏移（上限 0.06）、`weaponKick = 1`
- `updateRecoil(dt)` 指数衰减：`recoilRecover = 0.8`，连发累积、松开回正
- `updateCamera()` 中相机旋转 = 玩家视角 + 后坐偏移（关键：不能累加到 cameraAngleV，否则污染玩家视角）
- `updateWeaponBob()` 武器枪口上翘/后缩/偏摆，随后坐能量驱动
- CSS 准星扩散增强：recoil 时线散开 7px + 中点放大 1.6 倍，0.12s 平滑过渡

**参数手感验证**（Node 模拟）: 30 发连发上抬约 6.4°，松开 1 秒回正至约 2.9°。

**坑**: 最初把后坐力 `cameraAngleV += recoilPitch` 累加到玩家视角，衰减后回不来（相机只会一直上抬）——正确做法是独立偏移量，仅设置相机旋转时叠加。

## 修复 start.bat 双击不启动游戏

**现象**: 用户双击 start.bat 没有打开游戏。

**根因**: start.bat 用 UTF-8 无 BOM 写入中文内容，Windows cmd 默认用 GBK 代码页解析 .bat，导致中文行被拆成乱码"命令"执行（`'娴忚...' 不是内部或外部命令`），`if (...)` 括号块被破坏，`node server.js` 根本没执行，服务器未启动。

**修复**: 重写 start.bat 为**纯 ASCII 英文**，彻底规避 cmd 编码解析问题。

**验证**: 完整测试通过——服务器启动、端口 3000 监听、index HTTP 200、浏览器 start 命令执行成功。

**学习**: 已按 self-improving-agent 技能记录到 `.learnings/ERRORS.md`（ERR-20260807-001）和 `LEARNINGS.md`（LRN-20260807-001，已提升到 MEMORY.md）。
