# 2026-06-29 工作日志

## 修复射击后野怪变白 Bug

**问题**: 射击野怪后白色闪烁无法恢复，所有部位保持白色。
**根因**: 恢复代码通过 `c.name` 匹配部位（body/head/spike/belt），但肩膀、手臂、拳头、腿、脚、眼睛等部件未设置 name，导致无法匹配恢复逻辑。
**修复**:
1. 在 `createRedBuff()` 和 `createBlueBuff()` 末尾添加 `traverse`，为每个 mesh 存储 `userData.originalColor`
2. 将恢复代码简化为统一从 `userData.originalColor` 恢复，覆盖所有部件（包括 gem、rune、眼睛、四肢等）
